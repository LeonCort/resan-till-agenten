# Resan till agenten

En scrollbar berättelse om hur AI har gått från chattbot till agent, och vad det kan betyda för digitala kanaler.

**Sajten:** https://leoncort.github.io/resan-till-agenten/

`index.html` är en enda fristående fil med alla bilder inbäddade. Den går också att ladda ner och öppna direkt i en webbläsare, utan internetuppkoppling (typsnitten hämtas från Google Fonts när det finns uppkoppling).

Pressbilder och logotyper tillhör respektive företag.
